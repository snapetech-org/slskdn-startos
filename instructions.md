# slskdN

Open the StartOS **Web UI** interface to finish setup. Configure the Soulseek
username and password, shared library, download directory, and any optional
DHT or mesh features in the application settings.

Forward TCP port 50300 for incoming Soulseek traffic. UDP port 50300 is only
needed when enabling DHT, mesh rendezvous, or QUIC UDP features.

See the [slskdN documentation](https://github.com/snapetech/slskdn#readme)
for configuration and troubleshooting details.
